# NEXO Commerce AI — carregador de prévia

Branch temporária que contém somente o carregador para publicação em Streamlit no Render.
O código-fonte do aplicativo é fornecido exclusivamente como pacote comprimido nas **variáveis de ambiente privadas** do serviço; não está disponível neste repositório público.

A execução do ambiente de demonstração utiliza NEXO_DEMO=1 e NEXO_PREVIEW_PASSWORD. Não utilize para dados reais de clientes nem como sistema de produção. A base SQLite deste preview é efêmera.

Para uma implantação final: repositório privado com integração GitHub-Render, banco Neon dedicado, controles de autenticação/homologação fiscal/pagamentos/WhatsApp e backups.
